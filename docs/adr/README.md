# Architecture Decision Records (ADR)

Registro **breve** de decisiones de arquitectura y operación que cuestan revertir o que el equipo debe recordar al incorporar gente o módulos nuevos.

## Cómo agregar un ADR

1. Copiá el numerado siguiente (`0004-...md`).
2. Mantené secciones: **Contexto**, **Decisión**, **Consecuencias** (positivas / negativas / riesgos).
3. Estado típico: **Propuesta** → **Aceptada** (o **Reemplazada por ADR-00XX**).
4. Actualizá la tabla de este `README.md`.

No hace falta largo ensayo: una página suele alcanzar.
